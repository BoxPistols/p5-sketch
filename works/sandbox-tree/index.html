再帰で育つ木

branch() は枝を 1 本描いたあと、短くした枝を左右に 2 本、自分自身を呼んで描きます。枝が短くなったところで止まります。

⌘ / Ctrl + Enter でも実行できます。Esc のあと Tab で欄の外へ出ます

試してみる

  • len * 0.72 の 0.72 を変えると、枝の伸び方が変わる（0.8 を超えると重くなる）
  • rotate(0.45 + sway) と rotate(-0.5 + sway) の角度を変えると、木の形が変わる
  • if (len > 7) の 7 を大きくすると、枝分かれの回数が減る
