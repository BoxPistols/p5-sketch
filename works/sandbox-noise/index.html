ノイズの流れ

各点は、その場所の noise() の値を進む向きにして動きます。前のフレームを少しずつ暗くして、跡をゆっくり消しています。

⌘ / Ctrl + Enter でも実行できます。Esc のあと Tab で欄の外へ出ます

試してみる

  • p.x * 0.004 の 0.004 を大きくすると、流れが細かく渦を巻く
  • fill(250, 40, 7, 3) の最後の 3 を 0 にすると、跡が消えずに積もる
  • points の数（900）を減らすと、1 本ずつの線が見える
