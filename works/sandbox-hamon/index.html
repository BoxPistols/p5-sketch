三角関数の波紋

格子に並べた点の大きさと色を、中心からの距離の sin() で決めています。

⌘ / Ctrl + Enter でも実行できます。Esc のあと Tab で欄の外へ出ます

試してみる

  • d * 0.06 の 0.06 を大きくすると、波の間隔が詰まる
  • frameCount * 0.1 の符号を変えると、波が外から内へ向かう
  • dist() の中心を mouseX, mouseY にすると、マウスから波が広がる

書き換えた内容は保存されません。再読み込みすると元のコードに戻ります。このスケッチは Dev Album の p5.js マニュアルの作例を元にしています。
